# Portfólio

Este é um projeto de portfólio digital que reúne informações e projetos desenvolvidos como parte do curso. O objetivo é apresentar competências, experiências e habilidades por meio de uma aplicação web responsiva e interativa.

## ✅ Requisitos para rodar o projeto

- Node.js v18 ou superior
- npm ou yarn
- Navegador moderno (Chrome, Firefox, Edge)

## 🚀 Como rodar

```bash
git clone https://github.com/seu-usuario/portifolio.git
cd portifolio
npm install
npm start
